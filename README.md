# 아이엔골프 (iN GOLF) 홈페이지 – 기초 시안

정적 HTML/CSS/JS 한 페이지 사이트입니다. `index.html`을 브라우저로 열면 바로 볼 수 있습니다.

- `index.html` – 페이지 본문 (소개 / 서비스 / 파크골프 / 레슨 / 오시는 길)
- `css/style.css` – 스타일 (색상은 상단 `:root` 변수에서 변경)
- `js/main.js` – 모바일 메뉴, 스크롤 애니메이션

시안 단계 표시: 노란 밑줄(`.check`)은 웹 검색으로 찾은 정보라 확인이 필요한 항목이고,
`<!-- TODO -->` 주석은 실제 내용으로 채워야 할 자리입니다. 오픈할 때는 상단 시안 배너를 지우고
`<body class="final">`로 바꾸면 밑줄이 사라집니다.
